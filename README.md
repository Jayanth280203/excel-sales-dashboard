# 📊Excel Data Cleaning & Sales Analysis Dashboard

## 🧾Project Overview
This project focuses on cleaning raw sales data and building an interactive sales performance dashboard using Microsoft Excel.

## 🛠️Tools Used
- Microsoft Excel
- Pivot Tables
- Slicers
- Charts & Dashboards

## ✨Key Features
- Data cleaning (missing values, formatting, consistency)
- Region-wise sales analysis
- Category-wise sales & profit analysis
- Monthly revenue trend analysis
- Interactive dashboard with slicers

## 📌Business Insights
- Technology category contributes the highest sales and profit
- Furniture shows lower profit margins
- Clear seasonal trends in monthly revenue
- Regional sales performance varies significantly
